# Agent Instructions

## Public documentation boundary

This repository is public. Do not commit internal deployment runbooks, product
roadmaps, implementation plans, QA reports, live-test notes, operational details,
or sensitive identifiers here.

For maintainers with access, the canonical private location is the companion
`stalewell-docs` repository under `products/warden/internal/` and
`products/warden/qa/`. Do not link to those private paths from public documents.
When public documentation is needed, write a sanitized guide describing only
verified user-facing behavior.
