# Warden CLI

`@stlw/warden-cli` initializes, runs, and inspects Warden policy enforcement for local AI-agent projects.

```bash
npm install --global @stlw/warden-cli
warden init --environment development
warden config-validate
warden start
```

Use `warden proxy` for a stdio MCP policy gateway and `warden audit` to inspect the hash-chained ledger. See the [Warden manual](https://github.com/isiomaC/warden/blob/main/docs/MANUAL.md).
